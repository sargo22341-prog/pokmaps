# Recherche, lieux, objets et personnages

La recherche ouvre les fiches Pokémon, lieux, objets et attaques. Les lieux indiquent leurs rencontres et donnent
accès à la carte. Les objets présentent description, emplacement, usages et évolutions associées. Les personnages
détaillent équipes, dons, échanges, boutiques, soins, fossiles ranimés et récompenses. Les prix distinguent argent,
jetons, points de Buena, Points Combat et cendres, selon le jeu. Les liens avec la carte retrouvent l'objet ou le
personnage précis.

Hoenn ajoute les propriétés des baies sur les objets, les Concours sur les attaques et les décorations
dans les guides. Les services et revanches GBA conservent leurs conditions de scénario.

Les variantes du rival partagent une fiche : un sélecteur choisit le starter du joueur ; Jaune ajoute
les résultats des premiers combats. Le choix est mémorisé par jeu et partagé entre carte, fiches et guides.
Sur la Route 22 de Jaune, le premier combat affiche son équipe fixe sans ces choix ; le deuxième les propose.
Les revanches restent sur la fiche du dresseur ; les objets tenus sont affichés à partir de Johto.
