# Réglages et fonctionnement hors ligne

Aucune permission Internet ni service Google Play. Room lit la base générée ; DataStore mémorise jeu, captures, favoris et réglages. Les sprites animés se règlent séparément pour carte, listes de carte, Pokédex, fiche Pokémon, évolutions, fiches secondaires et recherche. Les sprites fixes sont la première image des animations, avec le même dessin.

La portée des captures s'applique aux espèces et aux formes de Zarbi : jeu, génération ou tous les jeux. Les captures restent enregistrées dans les versions d'origine. À propos présente les informations et sources du projet.
